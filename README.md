# STARTUP RUN — by STRATÉJEUX

Classroom game projected on the board (economics, management and marketing taught in English).
Teams draw a theme, a target and a constraint, imagine a startup, pitch it and get scored.

- One single file: `index.html` (HTML, CSS and JavaScript, no dependencies).
- Works offline: double-click the file to open it (recent Chrome, Edge, Firefox, Safari).
- The game is saved automatically in the browser: close it and continue later.
- Editable data at the top of the script: `CARDS` (themes, targets, constraints) and `CRITERIA` (scoring).
- Keyboard: `Space` start/pause the timer, `F` full screen, `M` sound on/off, `?` help.
